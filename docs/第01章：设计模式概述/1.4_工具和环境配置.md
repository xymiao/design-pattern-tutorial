# 工具与环境

- 安装 IntelliJ IDEA（推荐）
- 学习使用 UML 类图工具（PlantUML 或 Draw.io）
- 配置 Git 用于代码版本管理



# 工具

首先说明， 工具不限制。可以是 VSC， 也可以是  Eclipse， 当然推荐是一共 Idea C 或者 Idea U 的版本。 



不管是使用哪些工具代码 IDE 上面说的那些， 都可以安装其插件使用 UML 类图。 这个更不限制。 根据自己的使用习惯，重要的是要能画出来， 并能灵活使用。



代码版本管理：推荐都要用吧， 不管是自己平常的代码， 还是怎么， 当做一个备份也好， 自己想看代码的时候， 都能够随时的找到对应的代码示例，可以让自己查看， 不过， 现在 ai 的发展。 这个也只能成为你的知识库中的代码之一。
