# 设计模式

设计模式开始之前，要先知道一些概念。比方说 类、方法、构造方法、抽象类、接口，多态，事件等概念。这些是设计模式使用的基础。

希望能够知道，过程式编程和面向对象编程的含义。



这篇文章，尽量能够从零开始。从最简单的模式开始。

一个可以让自己回来翻自己的笔记。另一方面，也可以给看这篇文章的你，带来一些收获。仅此而已。



对于设计模式而言，这个要承认，的确不是给初学者准备的，也就是没有任何经验的人直接看意义不大，中间有断层，如果你没有任何编程的基础，还是推荐你先学习一个语言。本次的内容主要是以 Java 为基础进行编写。



当然如果，你对设计模式已经随心所欲，手中无剑似有剑，希望你能给我一些建议。 



当然任何人学习技术都不能无中生有，都是从临摹，创造，升华而来。



任何的学习都是从一个基础的地基开始，这样在上层建筑开始的时候，才会游刃有余，而不会出现裂缝，或者无法建造高楼大厦。



希望知道的一点，本系列教程并没有重新的创造一个模式， 而是站在巨人的肩膀上加上互联网的朋友，以及自己在实际工作编程中的理解编写出来的。

而学习的过程，会经过什么都不懂，不知道怎么用。学会了一点后，又觉得很好用，到处使用，而不知有误。再到学完模式后，觉得很多模式都很相似，无法区分清楚。再最后到灵活的使用。
