# 枚举单例模式

**枚举（Enum）**：实现单例模式是一种非常简洁且安全的方式。枚举单例模式由 Java 的枚举特性保证，能够天然地防止反射攻击、序列化问题以及多线程环境下的线程安全问题。

这是《Effective Java》作者 Joshua Bloch 推荐的单例实现方式。

## **应用场景**

- 需要防止反射和序列化破坏单例的场景
- 简单可靠的全局访问点

## **优缺点**

- ✅ 天生线程安全、防止反射攻击、自动处理序列化，代码简洁。
- ❌ **无法延迟加载**、无法继承其他类（枚举本质是final类）

## 代码示例

类图

代码

```java
public enum EnumSingleton {
    INSTANCE;
    
    public void doSomething() {
        System.out.println("Singleton Action");
    }
}
```



如何使用枚举单例

```java
public class Test {
    public static void main(String[] args) {
        // 获取单例实例
        EnumSingleton singleton = EnumSingleton.INSTANCE;

        // 调用单例的方法
        singleton.doSomething();
    }
}
```
