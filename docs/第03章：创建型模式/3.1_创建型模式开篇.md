# 创建型模式

这小节主要内容是创建型模式。

创建型模式（Creational Pattern）关注对象的创建过程，在软件开发中经常的使用该模式。 核心理论就是使对象的创建和使用分离。在使用对象时不需要关注对象的创建细节，从而降低系统的耦合度，让设计的开发更易于修改和创建。这里注意就是设计模式并非一直不变的，随着时间的变化，会有细微的变化导致命名的变化。灵活变通即可。

包含：

- 单例模式（Singleton Pattern）
- 简单工厂模式（Simple Factory Pattern）
- 工厂方法模式（Factory Method Pattern）
- 抽象工厂模式（Abstract Factory Pattern）
- 原型模式（Prototype Pattern）
- 建造者模式（Builder Pattern）



尽量做到， 每一个模式中都有不同的案例进行说明举例。
